# KoreVisuals

Клиент-конфигуратор для Minecraft Bedrock: собирает персональный `.mcpack` из модулей клиента.

## Как это работает

1. Пользователь открывает приложение, тыкает нужные фичи.
2. Приложение скачивает базовые модули с сервера, копирует выбранные, генерит `manifest.json` и пакует в `.mcpack`.
3. Импорт в Minecraft — готово.

## Структура репозитория

- `base/` — сырые модули клиента (по папкам)
- `manifest-version.json` — манифест версий для приложения
- `LICENSE` — MIT

## Сборка паков

Каждый модуль — отдельная папка в `base/`. Финальный `manifest.json` генерится приложением при сборке, не хранится готовым.
